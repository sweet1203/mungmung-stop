# 🐶 멍멍 STOP

강아지가 짖을 때 버튼을 꾹 누르면 사람 귀에는 잘 안 들리는 고음(12~22kHz)을 내는 짖음 훈련 웹앱입니다.

👉 바로 쓰기: https://sweet1203.github.io/mungmung-stop/

## 기능
- 꾹 누르는 동안 고음 재생 (최대 2초 자동 정지)
- 주파수·세기 조절, 스피커 확인
- 소리 사용 / 칭찬 횟수 기록

## 주의
- 폰 스피커는 진짜 초음파(20kHz 이상)를 잘 못 내서 전용 기기보다 약할 수 있어요.
- 소리만 쓰지 말고, 짖음이 멈추면 꼭 칭찬·간식으로 보상해 주세요.
- 1살 미만 강아지나 고양이·햄스터 등 다른 동물이 있는 곳에서는 쓰지 마세요.
